# Brainbridge AI (installable PWA)
Host this folder on any HTTPS static host (Netlify Drop, GitHub Pages, Cloudflare Pages), open the link in Chrome/Safari and use Install / Add to Home Screen.
Local test: `python3 -m http.server 8000` then open http://localhost:8000
After editing any file, change CACHE in sw.js (e.g. brainbridge-v2) so users get the update.
